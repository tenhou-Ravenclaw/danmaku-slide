# Chrome 拡張（Google スライド向け）

Google スライドの**発表ページに直接**弾幕を差し込む。

```
docs.google.com/presentation/d/.../present   ← Google のページ
  └ 差し込んだ <canvas>                        ← pointer-events: none
```

スライドと同じページの中に描くので、最前面もクリック透過も透過ウィンドウも要らない。
`pointer-events: none` を付けるだけでクリックはスライドへ素通りする。
[niconicomments](https://github.com/xpadev-net/niconicomments) が `<video>` の上に
canvas を重ねるのと同じ構造。

## これで消える問題

| | キャプチャ合成 | この拡張 |
|---|---|---|
| クリック透過 | 画面を分けて避ける | **素通りする** |
| 共有バーが映る | タブを選ぶと映る | **キャプチャしないので無い** |
| 比率が合わない | 余白を切り取って直す | **本物なので合っている** |
| アニメーション | 取り込んだ映像ごし | **本物** |
| 登壇者ビュー | 別ウィンドウに残す | **触らないのでそのまま** |
| 投影の繋ぎ方 | ブラウザを投影する | **いつも通り** |

## トラックIDはどこで作るか

いまは登壇者コンソールが唯一の発行場所。

```
https://df-hackathon-2026.web.app/speaker.html
```

名前を入れて「作る」と、URL が `?track=xxxxxxxx` に変わる。この8文字がトラックID。
同じ画面に QR と投稿URLも出る。

拡張にはIDでも投稿URLでも、どちらを貼っても通る。

```
abc23xyz
https://df-hackathon-2026.web.app/post.html?track=abc23xyz
```

## 入れる

```bash
npm run config      # 初回だけ
npm run build:ext
```

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」で `extension/` を選ぶ
4. 拡張のアイコンを押して、トラックID か運営からのURLを入れて保存
5. スライドを**発表モード**にする

すでに発表中だった場合は、保存時にそのタブを読み込み直す。

## 動いているか調べる

拡張のアイコンを押すと、いま何が起きているかと次の一手が出る。

| 出る文言 | やること |
|---|---|
| 拡張がこのページに入っていません | `chrome://extensions` で更新（↻）→ ページ再読み込み |
| Google スライドのタブが見つかりません | スライドを開く |
| 発表モードではありません | スライドショーを開始する |
| トラックが未設定です | IDを入れて保存 |
| トラックが見つかりません | IDが違う |
| 投稿が止められています | 登壇者コンソールで再開 |
| 動いています（0件） | まだ投稿が届いていない |

popup の先頭と `chrome://extensions` の両方に**ビルド時刻入りの版**が出る。
固定の版だと表示が変わらず、読み込み直せたのか古いままなのかを目で確かめられない。

```
版 0.1.1108.1620（2026-11-08 16:20:50）
```

`npm run build:ext` が最後に出す版と、`chrome://extensions` の版が一致していなければ、
**読み込み直せていない**。

### 発表中（全画面）は

全画面だとツールバーが出ないのでアイコンを押せない。
<kbd>⌘⇧Y</kbd> / <kbd>Ctrl+Shift+Y</kbd> で状態を出し消しできる。

<kbd>Esc</kbd> で全画面を抜ければツールバーが戻り、アイコンも押せる
（`/present` のままなので弾幕は動き続ける）。

## 作り

| ファイル | 役割 |
|---|---|
| `manifest.json` | 生成物。`npm run build:ext` で作る |
| `content.js` | 生成物。弾幕エンジンと Firestore を束ねたもの |
| `popup.html` / `popup.js` | トラックの指定 |
| `background.js` | いまは何もしない。将来の取っ掛かり |

content script はページの CSP に縛られないよう、依存ごと拡張側に束ねている。
ESM は使えないので IIFE で出す。

## 気をつけること

- 発表ページ（`/present`）でだけ動く。編集画面には差し込まない
- 全画面になると、その要素の中へ canvas を付け替える。外にいると描かれない
- 溜まっていた分は流さない。一斉に出ると画面が埋まる
- Google スライド専用。PowerPoint や Keynote では動かない（そちらはキャプチャ合成か透過シェル）

## 配布

Chrome ウェブストアの審査には数日かかる。間に合わない場合はデベロッパーモードでの
読み込みになるが、それは登壇者に求めるものとしては重い。
キャプチャ合成（インストール不要）を保険として残してある。
