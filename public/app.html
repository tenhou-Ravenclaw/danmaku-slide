お使いの環境を調べています
ダウンロードページを開く

配布ページから、お使いの環境のファイルを選んでください。

入れている余裕が無いときは「ブラウザ」で流せます。入れるものはありません。

入れてから流すまで

  1. ダウンロードした zip を展開して、アプリを開きます。
  2. 運営から届いた登壇用リンクを貼り付けます。
  3. 「スライドに流す」を押すと、透過したウィンドウが最前面に出ます。
  4. スライドを全画面にしても、弾幕はその上に残ります。

署名していないので、初回だけ macOS は右クリック→開く、 Windows は「詳細情報」→「実行」が要ります。 流している間は ⌘⇧C でクリックを下に通すかどうかを切り替え、 ⌘⇧X で終了します。

Chrome 拡張

Google スライドの発表ページに弾幕を差し込みます。ストアには出していないので、 zip を展開して Chrome に読み込んでください。

  1. 配布ページから danmaku-slide-extension.zip を取得して展開します。
  2. Chrome の chrome://extensions を開き、デベロッパーモードを入れます。
  3. 「パッケージ化されていない拡張機能を読み込む」で展開したフォルダを選びます。
  4. 拡張のアイコンを押し、登壇用リンクを貼って保存します。
